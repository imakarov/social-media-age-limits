Social media age limits by app and country

An open dataset of the minimum ages that apps state in their own terms, and the laws that set or raise age rules for children online. Every row links to its primary source and has the date it was checked. A blank age means the source does not state one.

Data: CC BY 4.0. Download apps.csv, apps.json, countries.csv, countries.json. Source and changelog on GitHub.

For a plain-language guide to what these ages mean for families, see Teach Kids Habits' explainer on social media age limits.

This is a reference, not legal advice. Terms and laws change; check the linked source before relying on a value. Corrections are welcome as GitHub issues with a link to the primary source.
